Umbraco Helper — Settings

General

Applied to any managed site that has no per-site override.

Umbraco panels/overlays appear instantly instead of animating in. Target elements are editable under “Tooltip selectors” → Sidebar animation targets.

Removes the extra margin under each field caption and puts the tooltip “ⓘ” button on the same line as the caption, so fields take less space. When off, spacing and tooltip position are unchanged.

Removes the vertical padding on Content tree items so more fit in the sidebar.

The green/yellow messages after publishing disappear after this long. 2000 = 2 seconds. Leave empty to keep Umbraco’s default timing.

Close sidebars with ESC

Umbraco pickers and the “Group filters” builder don’t close on ESC by themselves. This finds the top-most open overlay and clicks its dismiss button.

ESC only acts when one of these is open, so a stray Cancel button is never clicked by accident. Add the “Group filters” panel’s container here if it isn’t caught.

Submit with Enter

Ignored while you’re typing in a field or when a modifier key (Shift/Ctrl/Alt) is held, so it won’t save/publish by accident.

An open overlay’s button (e.g. “Submit”) is preferred over the main editor’s (“Save and publish...”).

Managed sites

The extension runs automatically on any page whose URL contains umbraco. Sites are added here as you visit them; use this list to disable the extension on a site or set a per-site mode. You can also pre-add a domain below.

Tooltip selectors

CSS selectors treated as "tooltips / help text" — one per line. Tune these after inspecting a real Umbraco page (right-click the help text → Inspect → copy its class).

Elements whose open/close animation is removed by the “Remove the slide/fade animation” setting — one selector per line.
